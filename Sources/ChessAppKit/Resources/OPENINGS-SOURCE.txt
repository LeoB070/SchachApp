Snapshot contains 3,865 opening records covering all 500 ECO codes A00–E99.
Converted TSV fields eco/name/pgn to JSON eco/name/moves. PGN move-number
tokens were removed; SAN tokens and English opening names are preserved.
All sequences were legally replayed using this app's Swift chess core.
This is a named-sequence collection, not a complete opening tree or a
transposition-aware position database.
