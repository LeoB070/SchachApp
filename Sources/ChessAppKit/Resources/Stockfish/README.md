# Stockfish-Binary-Platzhalter

Lege hier (Später) das Stockfish-Binary ab, damit es mit der App ausgeliefert wird:

    Resources/Stockfish/stockfish   (Apple Silicon macOS-Version, chmod +x)

Alternativ: Pfad in den App-Einstellungen angeben; Fallback ist `/opt/homebrew/bin/stockfish`
(`brew install stockfish`). Stockfish ist unter der GPLv3 lizenziert – Quelle:
https://github.com/official-stockfish/Stockfish
